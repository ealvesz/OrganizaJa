# Checklist de testes antes da entrega

Marque cada item depois de testar no Expo Go:

- [ ] O aplicativo abre sem apresentar erro.
- [ ] O nome OrganizaJá aparece sem sobreposição.
- [ ] É possível cadastrar uma despesa com valor decimal (ex.: 45,90).
- [ ] O aplicativo impede salvar descrição vazia.
- [ ] O aplicativo impede salvar valor zero ou negativo.
- [ ] A despesa aparece no painel e no histórico.
- [ ] A pesquisa encontra uma despesa pela descrição.
- [ ] O filtro por categoria funciona.
- [ ] É possível editar uma despesa.
- [ ] É possível excluir uma despesa após confirmação.
- [ ] É possível alterar o orçamento mensal.
- [ ] O total e o valor disponível são atualizados.
- [ ] Os gastos por categoria são exibidos.
- [ ] Os dados continuam salvos depois de fechar e abrir o app.
- [ ] A gravação de tela mostra o aplicativo real em funcionamento.
